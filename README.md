# Lab 4b - Client-Side Scripting (JSON and jQuery)

## Files
- books.json — two-book dataset (title, author, publicationYear, genres)
- books.html — fetches books.json and displays selected fields
- jquery-dom.html — jQuery equivalents of three native DOM operations

## Setup
1. Clone the repository.
2. Open the folder in VS Code.
3. **Start a local server** (do NOT open books.html via file://, or fetch() will fail):
   - VS Code Live Server: right-click books.html → "Open with Live Server", or
   - Terminal: `python -m http.server 8000` then visit `http://localhost:8000/books.html`
4. Open jquery-dom.html in the browser to verify the jQuery operations.
